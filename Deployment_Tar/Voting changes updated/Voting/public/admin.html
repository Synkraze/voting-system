Election setup

Name the election and optionally set an automatic close time. Ballots are refused once the deadline passes — a hard, server-enforced window.

Positions

Each position (e.g. President, Secretary) is voted on separately, and every position gets a "Not interested" option on the ballot. A position with a single candidate is decided by a >50% majority.

Import candidates by level

Upload one CSV for each position. Rows such as Name,Department, Level 4 create a separate ballot choice for each level in that file. Import all files before voting starts.

Roster upload

One eligible voter per line: student_id,name,email. The email is how voters sign in (email + one-time code), so it is required for them to vote. Re-upload only adds new rows.

Find a voter

Search the roster and check participation status. Ballot choices are never shown here.

Close & approve

Closing freezes the result and pins the audit root. Approval requires a passing verification and no tied position.

Admin accounts

Create or remove admin logins. Passwords must be at least 8 characters.

Backup & reset

Download a backup of the database and candidate photos before clearing data. Backups include the voter roster; keep them private. Signing keys and admin accounts stay in place.
